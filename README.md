# Honors_Welcome_Screens_Project

Touchscreen displays are playing crucial role in large or confusing buildings. 
The Queen Mother building is a computer science building, which has 2 floors and has a difficult rooms location.

The goal of this project is to develop an interactive digital navigation system for touchscreen displays that will assist users in navigating a multi-floor Queen Mother Building. It enables searches for rooms, lecturers, and facilities, with their positions displayed on a visual floor map. It is built with web technologies like as HTML, CSS, and JavaScript, and it prioritises usability and accessibility. It has a real-time search, interactive floor map, bespoke on-screen keyboard, and admin interface. Touch responsiveness, preventing repeated events, and proper map marker placement were among the major barriers.

The completed system improves navigation and suggests future enhancements such as real-time data integration and more accessible features.
